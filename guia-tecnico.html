🌍 Sistema de Tradução

Como Funciona

O sistema usa atributos data-pt e data-es em elementos HTML para armazenar textos em diferentes idiomas.

Exemplo:

<h1 data-pt="Bem-vindo" data-es="Bienvenido">
    Bem-vindo
</h1>

Quando o usuário clica em "ES", o JavaScript localiza todos os elementos com data-pt e data-es, e substitui o conteúdo interno pelo valor do atributo data-es.

Função de Tradução

function setLanguage(lang) {
    // Atualiza atributo data-lang
    document.documentElement.setAttribute('data-lang', lang);
    
    // Atualiza todos os elementos com data-pt/data-es
    document.querySelectorAll('[data-pt][data-es]').forEach(element => {
        if (element.tagName === 'TITLE') {
            element.textContent = element.getAttribute('data-' + lang);
        } else if (element.hasAttribute('placeholder')) {
            element.setAttribute('placeholder', element.getAttribute('data-' + lang));
        } else {
            element.textContent = element.getAttribute('data-' + lang);
        }
    });
    
    // Salva preferência
    localStorage.setItem('preferred-language', lang);
}

Adicionando Novo Texto Bilíngue

  1. Identifique o elemento HTML que contém o texto
  2. Adicione os atributos data-pt e data-es: 
    <p data-pt="Texto em português" data-es="Texto en español">
    Texto em português
</p>
  3. Certifique-se de que as aspas duplas dentro do atributo estejam escapadas como "
  4. Teste alterando para o idioma espanhol para verificar se funciona

Dica: Tratamento de Aspas

❌ Errado:

data-pt="Clique em "OK" para continuar"

✓ Correto:

data-pt="Clique em "OK" para continuar"

🎨 Sistema de Temas (Claro/Escuro)

Como Funciona

O modo escuro adiciona a classe high-contrast ao elemento <body> e muda as cores via CSS.

Toggle de Tema

toggleContrast.addEventListener('click', function() {
    document.body.classList.toggle('high-contrast');
    // Salva preferência
    localStorage.setItem('preferred-theme', 
        document.body.classList.contains('high-contrast') 
            ? 'high-contrast' 
            : 'light'
    );
});

Restauração de Tema ao Carregar

const savedTheme = localStorage.getItem('preferred-theme');
if (savedTheme === 'high-contrast') {
    document.body.classList.add('high-contrast');
}

Personalizando Cores

Para modificar cores do modo escuro, edite as regras CSS:

.high-contrast body {
    background: #1a1a1a;
    color: #ffffff;
}

.high-contrast a {
    color: #ffeb3b;
}

.high-contrast h1,
.high-contrast h2 {
    color: #00bfff;
}

📱 Sistema de Abas (Tabs)

Estrutura HTML

<div class="tabs">
    <button class="tab-button active" data-tab="sumario">
        📋 Sumário
    </button>
    <button class="tab-button" data-tab="introducao">
        🏠 Introdução
    </button>
    <!-- Mais abas -->
</div>

<div id="sumario" class="tab-pane active">
    Conteúdo do Sumário
</div>

<div id="introducao" class="tab-pane">
    Conteúdo da Introdução
</div>

Lógica JavaScript

document.querySelectorAll('.tab-button').forEach(button => {
    button.addEventListener('click', function() {
        const targetTab = this.getAttribute('data-tab');
        
        // Remove active de todos
        document.querySelectorAll('.tab-button').forEach(b => 
            b.classList.remove('active')
        );
        document.querySelectorAll('.tab-pane').forEach(p => 
            p.classList.remove('active')
        );
        
        // Ativa apenas o clicado
        this.classList.add('active');
        document.getElementById(targetTab).classList.add('active');
    });
});

Adicionando Nova Aba

  1. Adicione o botão da aba: 
    <button class="tab-button" data-tab="nova-aba">
    🆕 Nova Aba
</button>
  2. Adicione o painel de conteúdo: 
    <div id="nova-aba" class="tab-pane">
    Conteúdo da nova aba
</div>
  3. O JavaScript existente automaticamente fará a aba funcionar!

🔍 Debugging e Troubleshooting

Verificar Estado de Tradução

Abra o Console do Navegador (F12) e execute:

// Verificar idioma atual
document.documentElement.getAttribute('data-lang');

// Contar elementos com traducao
document.querySelectorAll('[data-pt][data-es]').length;

// Verificar localStorage
localStorage.getItem('preferred-language');
localStorage.getItem('preferred-theme');

Elementos Sem Tradução

Para encontrar elementos que faltam tradução:

// Listar elementos sem data-pt ou data-es
document.querySelectorAll('p, h1, h2, h3, h4, span').forEach(el => {
    if (!el.hasAttribute('data-pt') || !el.hasAttribute('data-es')) {
        console.log('Falta tradução:', el);
    }
});

Testar Tema Escuro

// Forçar modo escuro
document.body.classList.add('high-contrast');

// Remover modo escuro
document.body.classList.remove('high-contrast');

// Verificar se está em modo escuro
document.body.classList.contains('high-contrast'); // true/false

💬 FAQ Técnico

P: Posso usar frameworks como React ou Vue?

R: Sim, mas seria necessário refatorar completamente. A arquitetura atual é vanilla JavaScript para máxima compatibilidade e leveza.

P: Como adiciono imagens?

R: Coloque imagens na pasta assets/page_X/ e referencie como <img src="assets/page_X/imagem.png">

P: Posso minificar o HTML?

R: Sim! Use ferramentas como html-minifier. Isso reduzirá o tamanho do arquivo em ~30%.

P: O sistema funciona sem internet?

R: Sim! É um arquivo HTML estático que roda completamente no navegador local.

P: Como faço backup das mudanças?

R: Use Git! git commit cria um snapshot de todas as mudanças. Você pode reverter a qualquer momento com git revert.
