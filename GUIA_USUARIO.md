# 🌍 Guia de Uso - Apostila Arrais Amador Multilíngue

## 🚀 Como Começar

### Passo 1: Abrir o Arquivo
1. Localize o arquivo **`Apostila_Multilingue.html`** na pasta do projeto
2. Clique duas vezes para abrir em seu navegador web favorito
   - Chrome ✓
   - Firefox ✓
   - Safari ✓
   - Edge ✓

### Passo 2: Selecionar Idioma
- Clique em um dos botões de idioma no topo da página:
  - **🇧🇷 Português** - Brasileiro (padrão)
  - **🇪🇸 Español** - Espanhol (Castelhano)
  - **🇺🇸 English** - Inglês (Americano)

### Passo 3: Navegar pelos Módulos
Use as abas na parte superior para acessar:
- **📋 Sumário** - Visão geral de todos os módulos
- **🏠 Introdução** - Apresentação da escola e objetivos
- **🚢 Módulo 1** - Conhecendo uma Embarcação
- **⚙️ Módulo 2** - Propulsão e Outros Sistemas
- **🛡️ Módulo 3** - Segurança e Legislação
- **🧭 Módulo 4** - Navegação e Manobras
- **🔗 Módulo 5** - Cabos e Nós
- **📖 Glossário** - Termos Náuticos Explicados

## 🎨 Recursos Disponíveis

### Modo Escuro
- Clique no ícone **🌙** (Modo Escuro) no canto superior direito
- Útil para ler por longos períodos
- Reduz fadiga ocular

### Salvamento Automático
- Seu idioma escolhido é **automaticamente salvo**
- Ao recarregar a página, o último idioma selecionado será carregado
- Nenhuma configuração necessária!

## 📚 O que Contém Cada Módulo

### 🚢 Módulo 1 - Embarcação
- Definição de embarcações
- Classificação (finalidade, material, propulsão)
- Partes de uma embarcação (Proa, Popa, Meia-nau, etc.)
- Medidas lineares (comprimento, boca, calado, etc.)
- Movimentos da embarcação
- Sistemas de fundeio

### ⚙️ Módulo 2 - Propulsão
- Ciclos de motor (4-tempos Otto, 2-tempos, Diesel, Wankel)
- Sistemas de refrigeração (ar, água doce, água salgada)
- Sistema de lubrificação
- Sistema hidráulico
- Sistema elétrico
- Injeção de combustível

### 🛡️ Módulo 3 - Segurança
- Procedimentos de embarque
- Segurança durante navegação
- Procedimentos de retorno
- Triângulo do fogo
- Classes de fogo (A, B, C, D)
- Métodos de extinção
- Direitos de passagem

### 🧭 Módulo 4 - Navegação (RIPEAM)
- Fundamentos de navegação
- Definições de embarcações conforme RIPEAM
- Preferências de manobra
- Sinais sonoros (apito)
- Sistema de balizamento
- Marcas cardeais

### 🔗 Módulo 5 - Cabos e Nós
- Nó Direito
- Nó de Oito
- Lais
- Volta Fiel
- Escota
- Volta ao Cunho
- E mais...

## 🔍 Como Buscar Informações

### No Glossário
1. Clique na aba **📖 Glossário**
2. Escolha o idioma desejado
3. Procure pelo termo náutico (ex: "Âncora", "Mastro", "Vela")
4. Leia a definição traduzida

### Nos Módulos
- Role para cima/baixo para ler o conteúdo
- Os títulos e subtítulos estão em negrito
- Use Ctrl+F (ou Cmd+F no Mac) para buscar palavras específicas

## 💡 Dicas Úteis

   - Estude em português primeiro
   - Depois revise em espanhol

   - Funciona em tablets e smartphones
   - O layout se adapta automaticamente
   - Toque nos botões de idioma para mudar

## ⚠️ Troubleshooting (Solução de Problemas)

### Problema: Textos aparecem em branco ou não aparecem
**Solução**: 
- Recarregue a página (F5 ou Cmd+R)
- Limpe o cache do navegador (Ctrl+Shift+Delete)
- Tente em outro navegador

### Problema: Botões de idioma não funcionam
**Solução**:
- Abra o Console do Navegador (F12)
- Procure por mensagens de erro vermelho
- Certifique-se de que `translations.js` está na mesma pasta
- Contate o suporte com screenshot do erro

### Problema: Idioma não é salvado
**Solução**:
- Verifique se localStorage está habilitado
- Navegadores em modo privado podem não salvar dados
- Tente usar o navegador normalmente

### Problema: Parece estar carregando lentamente
**Solução**:
- É normal na primeira carga
- Após isso, será muito rápido (cache do navegador)
- Use Modo Escuro se preferir reduzir o consumo de recursos
