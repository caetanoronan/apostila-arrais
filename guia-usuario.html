❓ Perguntas Frequentes

P: Como faço para alternar entre Português e Espanhol?

R: Clique nos botões PT ou ES no topo da página (barra de header). O idioma será alterado instantaneamente em todo o conteúdo.

P: Minha preferência de idioma é salva?

R: Sim! Sua preferência é automaticamente salva no seu navegador usando localStorage. Ao recarregar a página, o idioma que você escolheu será mantido.

P: O que é o Modo Escuro?

R: É um modo de alto contraste que muda as cores do site para preto/branco, reduzindo fadiga ocular e melhorando a legibilidade em ambientes com pouca luz.

P: Meu navegador está mostrando um aviso de segurança. É seguro?

R: Sim, é perfeitamente seguro. O arquivo HTML é local e não contém conteúdo malicioso. Você pode ignorar qualquer aviso de segurança do navegador.

P: Posso usar esta apostila offline?

R: Sim! Basta fazer download do arquivo HTML e abri-lo diretamente no seu navegador. Nenhuma conexão com a internet é necessária.

P: Quantas questões tem em cada simulado?

R: Cada simulado contém aproximadamente 20-30 questões de múltipla escolha, similar ao formato da prova oficial de Arrais Amador.

P: Como faço para imprimir a apostila?

R: Pressione Ctrl+P (ou Cmd+P no Mac) para abrir a janela de impressão do navegador. Você pode ajustar as configurações conforme necessário.

💡 Dicas e Truques

  • Busca rápida: Pressione Ctrl+F para buscar uma palavra na página atual
  • Atalho de idioma: Memorize os botões PT/ES para trocar rapidamente entre idiomas
  • Modo de impressão: Use Modo Escuro para economizar tinta ao imprimir
  • Glossário: Use o glossário para entender termos náuticos desconhecidos

🔧 Solução de Problemas

O idioma não está mudando

  • Verifique se o arquivo foi aberto corretamente no navegador
  • Tente recarregar a página (F5)
  • Limpe o cache do navegador se o problema persistir

O Modo Escuro não está funcionando

  • Clique no botão de contraste novamente
  • Recarregue a página para restaurar o tema salvo

As imagens não estão aparecendo

  • Verifique se a pasta assets/ está no mesmo local que o arquivo HTML
  • As imagens devem estar nos subdiretórios assets/page_X/

Os links não estão funcionando

  • Se acessar via GitHub Pages, certifique-se de que os arquivos foram commitados e pushados
  • Verifique a URL do repositório GitHub Pages
