## 📋 Sobre o Projeto

Esta apostila foi desenvolvida com foco em **acessibilidade** e **usabilidade**, oferecendo uma experiência de aprendizado moderna e interativa para candidatos ao exame de Arrais Amador.

### ✨ Características Principais

- 🎨 **Modo Claro/Escuro**: Alterne entre temas para conforto visual
- 📱 **Design Responsivo**: Adaptado para desktop, tablet e mobile
- ♿ **Acessibilidade**: Compatível com leitores de tela e navegação por teclado
- 🖼️ **Recursos Visuais**: Diagramas, ilustrações e GIFs educativos
- 📝 **Exercícios Interativos**: Questões de revisão e simulados
- 🌐 **Terminologia Internacional**: Glossário náutico em português e inglês

---

## 📚 Conteúdo Programático

### **Módulo 1** - Conhecimentos Gerais sobre Embarcações
- Nomenclatura náutica
- Partes da embarcação
- Tipos de embarcações
- Movimentos e manobras
- Equipamentos de fundeio

### **Módulo 2** - Propulsão e Sistemas
- Motores marítimos (diesel, gasolina, elétrico)
- Sistemas elétricos e hidráulicos
- Hélices e sistemas de transmissão

### **Módulo 3** - Segurança da Navegação
- Prevenção e combate a incêndio
- Equipamentos de segurança
- Primeiros socorros
- Procedimentos de emergência

### **Módulo 4** - Legislação e Regras de Navegação
- RIPEAM (Regulamento Internacional)
- Sistema de balizamento IALA-B
- Sinais sonoros e luminosos
- Direitos e deveres do condutor

### **Módulo 5** - Manobras e Navegação
- Técnicas de atracação e desatracação
- Navegação costeira
- Uso de instrumentos náuticos
- Cartas náuticas

## 🛠️ Como Usar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/caetanoronan/apostila-arrais.git
   ```

2. **Navegue até a pasta:**
   ```bash
   cd apostila-arrais
   ```

3. **Abra o arquivo HTML:**
   - Clique duas vezes em `Apostila_arras_teste_08_clone.html`
   - Ou abra com seu navegador preferido
